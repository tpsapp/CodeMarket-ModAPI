# Security Policy

## Supported Versions

| Version | Supported |
| :--- | :---: |
| `1.0.x` | Yes |

## Reporting a Vulnerability

If you discover a security vulnerability in `CodeMarket.ModAPI` (such as path traversal in manifest/sidecar handling, unsafe file I/O, or arbitrary code execution in zero-code JSON data packs), please report it responsibly:

* **Email:** `tpsapp@hotmail.com`
* **GitHub:** Open a Private Vulnerability Report on `tpsapp/CodeMarket-ModAPI`.

Please include steps to reproduce, the affected version, and any relevant `BepInEx/LogOutput.log` excerpts. Do not open a public issue for undisclosed security vulnerabilities.
